# Figure-8 三体系统演示

## 概述

这个演示展示了一个稳定的三体系统，三个质量相等的天体沿着8字形轨道运动。这是一个经典的稳定三体解，由 Chenciner & Montgomery 在 2000 年发现。

## 特性

- **稳定的周期轨道**：三个天体永远不会碰撞或飞离
- **总动量为零**：系统质心保持静止
- **对称性**：每个天体都经过其他两个天体的初始位置
- **时间反演对称**：轨道可以反向运行

## 运行演示

`ash
python demo_figure8.py
`

## 操作说明

### 视图控制
- **鼠标滚轮**：缩放视图
- **鼠标中键拖拽**：平移画布
- **重置摄像机**：将视图重置到初始状态
- **适应全部**：调整视图以显示所有天体

### 播放控制
- **暂停/继续**：暂停或继续模拟
- **单步**：执行一步模拟
- **时间缩放**：调整模拟速度（0.1x 到 100x）

### 参考系
- **跟随质心**：自动将视图中心保持在系统质心（默认关闭）
- **重置参考系**：重新计算质心并平滑过渡

### 模式切换
- **模拟模式**：使用模拟单位（MU, DU, TU）
- **科学模式**：显示现实单位（如果有映射）

## 科学意义

Figure-8 轨道是三体问题中少数几个已知的稳定周期解之一。它的发现证明了三体问题中存在规则的运动模式，而不仅仅是混沌行为。

这个解具有以下对称性：
- **交换对称**：任意两个天体可以交换位置
- **时间反演对称**：轨道可以反向运行
- **旋转对称**：轨道在旋转180度后保持不变

## 技术细节

- **积分器**：Velocity Verlet（辛积分器，保持能量守恒）
- **时间步长**：dt = 0.001（小步长保证精度）
- **引力常数**：G = 1.0（模拟单位）
- **软化因子**：ε = 1e-8（防止奇点）

## 观察建议

1. **开启轨迹显示**：可以看到8字形轨道的完整形状
2. **使用跟随质心**：保持视图稳定
3. **调整时间缩放**：慢速观察细节，快速观察整体模式
4. **切换视角**：使用缩放和平移探索不同尺度
